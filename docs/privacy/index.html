Privacy Policy

Thymer Google Calendar is a plugin that runs entirely inside your own Thymer application. Last updated: 1 October 2026.

What the plugin accesses

With your consent it uses the Google Calendar API with two scopes: calendar.calendarlist.readonly, to list your calendars so you can choose which ones to sync, and calendar.events, to read events from the calendars you select and to create or update events when you change them in Thymer. It never deletes events and never changes calendar settings or sharing.

Where your data goes

  • Calendar data is copied only into your own Thymer workspace, where it is subject to Thymer's own storage and sync.
  • OAuth tokens are stored locally in your Thymer application on your device. They are never sent anywhere except to Google.
  • The plugin has no servers of its own. Nothing is collected, logged, analysed, shared or sold by the plugin author. The sign-in return pages (this site) only forward the response back into Thymer and store nothing.
  • Place suggestions (optional, can be switched off in the settings): the text you type in an event's Location is sent to Geoapify, or to OpenStreetMap's Photon search (photon.komoot.io) when Geoapify is unavailable, to look up matching places. No Google data is sent with it.
  • Google user data is never transferred to anyone else and is never used for advertising.

Your choices

  • You choose which calendars sync, and how far back and forward.
  • Disconnecting an account in the plugin's settings revokes its token with Google and removes it from the device.
  • You can also remove access at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

The plugin's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
